♡ My Projects

Technologies: HTML, CSS, JavaScript

02. Interactive Java Quiz System

A comprehensive desktop quiz application built with Java. This project features a complete Graphical User Interface (GUI), dynamic question handling, and gamification elements. It also includes a reward system and a file storage manager to track user scores and progress.

Technologies: Java, Object-Oriented Programming (OOP), GUI

03. Sarawak Heritage Online Auction (SHAA) Database System

A robust web-based database system designed for an online auction platform. The project features a fully normalized relational database (up to 3NF) with a Crow's Foot ERD. It includes advanced SQL triggers, user authentication, dynamic bidding history, and automated payment and delivery tracking.

Technologies:HTML, PHP, MySQL (phpMyAdmin), XAMPP

04. KUTS ART Mobile App UI/UX Design

A high-fidelity mobile application prototype designed for the Kuching Urban Transportation System (KUTS) Autonomous Rapid Transit (ART). The design focuses on an interactive map module featuring station routing, place-of-interest filtering, and an intelligent search system. It also incorporates accessibility features for visually impaired users and a seamless ticket booking flow, validated through System Usability Scale (SUS) testing.

Technologies: Figma, UI/UX Design, Prototyping, Usability Testing

05. Trash Collector:OpenGL Game

An interactive environmental conservation game developed using C++ and the OpenGL library. Inspired by classic 70s-90s arcade games, it features custom polygon rendering, character animations with joint limitations, and a two-level scoring system. The game challenges players to collect trash to progress, promoting environmental awareness through an engaging, custom-built UI.

Technologies: C++, OpenGL, Computer Graphics, VS Code
